# C Mark Logo

The logo of [[Cambridge Europe Network CIC]] is a letter C built from 17 triangles in blue, white, red and gold, each filled with its own linear gradient (`cm0` to `cm16`).

On the [[Index Page]] it is defined once as `<symbol id="cmark">` in a hidden SVG at the top of `<body>` and reused with `<use href="#cmark">`. `favicon.svg` is a separate copy of the same polygons and gradients, so a logo change has to be made in both files. The [[Hero Arch]] stretches the same facet style into a bridge.
